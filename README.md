**Vibe is Made for the TrimUI Brick**

This app was designed around the sensibilities of the Brick and its features. As such, you have stuff like the LEDs changing color to match the current album art. There is also (unstable) USB transfer support. Vibe can also continue playing music in the background as you play your games, with hotkeys to pause, skip, and go back.

Vibe comes with a bunch of pre-loaded themes. If you'd like to make your own, simply edit the themes.ini file.

Vibe also has yt-dlp implemented to easily download songs from YouTube Music. It's a bit jank, but it works. If metadata is messed up or not to your liking, there's a built-in tag editor. Songs are downloaded to /Music/Downloads.


**Controls**

Vibe has a lot of controls dedicated to individual buttons presses. Controls also differ if you're on a menu or the Now Playing screen.


*Main Menu*


| Button | Action |
| :--- | :--- |
| **Select** | Turn screen off/on |
| **Menu** | Resume, Keep Playing in Background, Search songs, Settings, Quit |
| **A** | Accept |
| **B** | Back |
| **Y** | Resume playback / Now Playing screen |
| **L / R** | Switch between tabs |
| **Start** | Random shuffle |



*Now Playing Screen*


| Button | Action |
| :--- | :--- |
| **Select** | Turn screen off/on |
| **Menu** | Resume, Equalizer, Edit Tags, Add to Playlist, Keep Playing in Background, Search songs, Settings, Quit |
| **A** | Accept |
| **B** | Back |
| **Y** | Repeat |
| **X** | Shuffle |
| **L / R** | Skip Track |
| **L2 / R2** | Change visualizer |
| **Start** | Go to album of current song |
| **D-Pad Left / Right** | Skip 10 seconds |



*Keyboard*


| Button | Action |
| :--- | :--- |
| **A** | Type |
| **B** | Delete |
| **Y** | Shift |
| **L / R** | Move cursor |
| **L2** | Close keyboard |
| **Start** | Enter |


An extra note is that you can delete created playlists by pressing X on it twice.

**Important note: if you get audio stutters, turn wifi off.**
